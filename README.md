# Kevin's HA Add-ons

Personal Home Assistant add-on repository.

## Add-ons

| Add-on | Description |
|--------|-------------|
| [Claude Code](claudecode/) | Claude Code in the HA sidebar, with access limited to the HA config directory |

## Attribution

`claudecode/` is adapted from the Claude Code add-on in [robsonfelix/robsonfelix-hass-addons](https://github.com/robsonfelix/robsonfelix-hass-addons) (MIT), copied from commit [`2870702fa97a953dbb542536eba10ecd919591d4`](https://github.com/robsonfelix/robsonfelix-hass-addons/tree/2870702fa97a953dbb542536eba10ecd919591d4/claudecode). It's been cut down to remove Supervisor, Docker and UART access.

## Installation

**Settings** → **Add-ons** → **Add-on Store** → **⋮** → **Repositories** → add `https://github.com/qkevinto/ha-addons`
